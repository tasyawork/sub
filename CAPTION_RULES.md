# Правила эмоциональных субтитров для разработки

Короткая спецификация для ИВИ-прототипа Caption with Intention.

## 1. Что нельзя менять между спикерами

| Параметр | Значение | Правило |
|---|---|---|
| Шрифт | IVI Sans Base Bold | Один на все реплики |
| Насыщенность | `wght = 750` | Жирный, одинаковый |
| Ширина глифов | `wdth = 100` | Не менять по спикеру |
| Базовый размер | `5%` высоты экрана | Не менять по эмоции строки |
| Курсив | нет | Даже закадр не курсивом в этой версии |

По умолчанию все субтитры **белые**, а активные и уже произнесённые буквы
окрашиваются только голубым (`#00A5FF`). Красный акцент не используется.

При `speakerColors = true` спикеры отличаются только цветом. Эмоции **не меняют**
палитру, шрифт и насыщенность.  
Они меняют только движение активного слова (`transform` / `opacity` / лёгкий `filter`).

## 2. Сигналы голоса → базовые эффекты

Все эффекты применяются **только к активному слову**.  
Метрики строки не меняются, соседние слова не прыгают.

### Громкость → увеличение
```
volumeDelta = loudnessWord - medianLoudness(speaker)
cap   = shout ? 1.20 : 1.10          // shout = крик, драка, паника
scale = clamp(1.02 + volumeDelta * kVolume, 1.02, cap)
```
- Нормализуем относительно **личной** медианы спикера, не глобальной.
- Шёпот: `1.02` (почти без роста)
- Обычная речь: `1.03–1.05`
- Акцент / спор: `1.06–1.08`
- Ругань, нажим: `1.09–1.12`
- **Крик, ярость, драка: `1.13–1.20`** — только при `shout = true`

`shout` включаем, когда одновременно выполняется хотя бы два условия:
громкость слова `> +6 dB` от медианы спикера, длительность гласной растянута,
pitch выше личной медианы, в сцене есть физическое действие.

### Режим `shout` — как «бьёт» слово
Крик отличается не только размером, но и **характером движения**:

| Параметр | Обычная речь | `shout` |
|---|---|---|
| Атака (набор scale) | `450–700 ms` | `180–220 ms` |
| Easing | `cubic-bezier(.16,1,.3,1)` | `cubic-bezier(.12,.85,.25,1)` |
| Непрозрачность непроизнесённых слов | `0.9` | `0.6` (фокус на активном) |
| Тень | базовая | усиленная (слово «выдавливается» из кадра) |

Важно: быстрая атака + **плавный откат**. Резкий откат читается как дёрганье.

### Акцент внутри строки (`accent`)
Ключевое слово реплики может получить **персональный пик** выше базового `scale` строки:
```
wordScale = clamp(lineScale * accentMul, 1.02, cap)   // accentMul = 1.01…1.06
```
- В строке максимум **2 акцентных слова**, иначе теряется иерархия.
- Акцент ставим на ударное слово («тварь», «Хватит», «Сдохни»), не на служебное.
- Разница между акцентом и базой строки — не меньше `0.03`, иначе её не видно.

### Протяжность / давление → лёгкое растяжение
```
if durationWord >= 1.4 * medianDuration(line):
  stretchX = clamp(1 + (durationRatio - 1) * 0.04, 1.00, 1.06)
else:
  stretchX = 1.00
```
Итог: `scaleY = scale`, `scaleX = scale * stretchX`

### Тональность (pitch) → микросдвиг по вертикали
```
pitchDelta = pitchWord - medianPitch(speaker)
pitchY = clamp(pitchDelta * kPitch, -2px, +2px)
```
- Выше обычного тона спикера → чуть вверх
- Ниже → чуть вниз
- Не больше ±2 px

## 3. Пул эмоций и анимации

Каждому слову можно назначить одну **базовую эмоцию** (`emotion`) и опционально силу (`intensity` = `0..1`).

Правило приоритета:
1. Сначала считаем базовые сигналы (громкость / pitch / длительность).
2. Потом поверх накладываем **эмоциональный motion-профиль**.
3. Если профили конфликтуют — берём эмоцию, но режем амплитуду по лимитам ниже.
4. При `prefers-reduced-motion` оставляем только цвет + лёгкий scale ≤ `1.03`, без тряски и пульса.

### Общие лимиты для всех эмоций

| Параметр | Спокойная сцена | Сцена высокой интенсивности (`shout`) |
|---|---|---|
| Scale | `1.00–1.10` | `1.00–1.20` |
| Stretch X | `1.00–1.06` | `1.00–1.06` |
| Сдвиг Y активного слова | `0 px` | `0 px` |
| Тряска слова | `≤ 0.8 px` | `≤ 1.1 px` |
| Толчок строки (`jolt`) | `0` | `≤ 5.5 px`, только на удар в кадре |
| Длительность motion | `450–700 ms` | `180–460 ms` |

Правило совместимости: если `scale > 1.14`, то тряска ≤ `0.8 px` — иначе слово
становится нечитаемым. Тряска и акцентный пик одновременно допустимы только
у `rage` и `pain`.

---

### `neutral` — нейтрально
**Когда:** ровная речь без явного напряжения.  
**Анимация:** мягкий рост `1.03–1.04`, без тряски.  
**Правило:** дефолт, если эмоцию определить нельзя.

### `calm` — спокойствие
**Когда:** тихий уверенный тон, ровный pitch.  
**Анимация:** почти незаметный рост `1.02`, easing длиннее (`650–700 ms`).  
**Правило:** не добавлять bounce и тряску.

### `whisper` — шёпот
**Когда:** очень тихо, часто с паузами.  
**Анимация:** scale `1.01–1.02`, opacity активного слова `0.82 → 0.95`.  
**Правило:** не увеличивать сильно; читаемость важнее «эффекта тишины».

### `soft` — нежность / тепло
**Когда:** мягкая интонация, низкая атака звука.  
**Анимация:** scale `1.03`, лёгкий подъём `−1 px`, без резких углов easing.  
**Правило:** движение должно ощущаться «мягким», без тряски.

### `joy` — радость
**Когда:** светлый тон, ускорение речи, улыбка в голосе.  
**Анимация:** scale `1.05–1.07` + микроподъём `−1.5 px` (слово чуть «всплывает»).  
**Правило:** без тряски; не использовать для сарказма.

### `amusement` — усмешка / лёгкий смех
**Когда:** короткие всплески, прерывистый ритм.  
**Анимация:** 1–2 мягких пульса scale `1.03 → 1.06 → 1.03` за время слова.  
**Правило:** пульс только на активном слове, частота ≤ 2 раза.

### `interest` — интерес / любопытство
**Когда:** восходящий тон в конце слова/фразы.  
**Анимация:** scale `1.04` + pitchY вверх до `−2 px` к концу слова.  
**Правило:** сдвиг только вверх, без боковой тряски.

### `surprise` — удивление
**Когда:** резкий старт, короткий пик громкости.  
**Анимация:** быстрый, но плавный рост `1.02 → 1.08` за `180–220 ms`, затем удержание.  
**Правило:** не делать overshoot выше `1.10`; после пика не «прыгать» обратно резко.

### `confusion` — растерянность
**Когда:** паузы внутри фразы, плавающий pitch.  
**Анимация:** scale `1.03` + очень медленный горизонтальный дрейф `±0.4 px`.  
**Правило:** дрейф медленный (`2–3 Hz` нет; скорее `0.4–0.7 Hz`), иначе будет похоже на страх.

### `anxiety` — тревога
**Когда:** ускоренный темп, неровный breathy тон.  
**Анимация:** scale `1.04` + мелкая тряска `0.3–0.5 px`, `7–9 Hz`.  
**Правило:** тряска слабее, чем у страха; не сочетать с сильным stretch.

### `fear` — страх
**Когда:** дрожь в голосе, сжатая речь, нестабильный pitch.  
**Анимация:** слово **чуть-чуть плавно трясётся**: amplitude `0.4–0.8 px`, `8–12 Hz`, плюс scale `1.03–1.05`.  
**Правило:**
- трясём только активное слово, не всю строку;
- easing у тряски синусоидальный, без рывков;
- при `intensity < 0.4` amplitude ≤ `0.4 px`;
- при Reduce Motion — только цвет, без тряски.

### `sadness` — грусть
**Когда:** замедление, понижение тона.  
**Анимация:** scale `1.02–1.03`, сдвиг вниз `+1…+2 px`, чуть длиннее fade-in цвета.  
**Правило:** никаких «весёлых» подъёмов и пульса.

### `fatigue` — усталость
**Когда:** вялая атака, просадка энергии к концу слова.  
**Анимация:** scale стартует `1.04` и мягко падает к `1.01` к концу слова.  
**Правило:** не путать с грустью: здесь именно «сдувание», а не опускание всей строки.

### `anger` — злость
**Когда:** жёсткая атака, выше громкость, короткие ударные слова.  
**Анимация:** scale `1.10–1.13`, stretchX `1.03–1.05`, сдвиг вверх до `2 px`, `shout = true`.  
**Правило:** движение «плотное», но плавное (атака `300–340 ms`), без тряски. Акцент — на оскорблении.

### `rage` — ярость / крик в драке
**Когда:** срыв на крик, физическая борьба, речь на пределе.  
**Анимация:** scale `1.14–1.20`, stretchX до `1.06`, сдвиг вверх `2–2.5 px`,
допускается тряска `≤ 0.8 px` и `jolt` строки `2–3.5 px`.  
**Правило:**
- ставим только на действительно кричащие реплики, не на всю сцену подряд;
- два акцентных слова максимум («Держи её!», «Сдохни!»);
- если реплика повторяется («Давай! Давай!») — второй повтор чуть сильнее первого.

Для исключительно сильной реплики допускается `super = true`: активное слово
за `700 ms` проходит мягкую «компрессию → рост → стабилизацию» (`scale .96`
→ целевой scale → покой). Нижняя граница слова всё время остаётся на месте.
В режиме единого акцента
добавляется короткое свечение `#00A5FF`. Профиль используется только для пиков
сцены, а не для каждой громкой фразы.

### `panic` — паника, крики вокруг
**Когда:** несколько голосов одновременно, неразборчивый шум-крик.  
**Анимация:** scale `1.08–1.10`, stretchX `1.04`, тряска `0.6–0.7 px` постоянно.  
**Правило:** используем для описательных строк `[крики вокруг]`, а не для реплик.

### `irritation` — раздражение
**Когда:** злость слабее, но с нажимом на отдельные слова.  
**Анимация:** scale `1.05–1.07` + короткий акцент в первой трети слова.  
**Правило:** слабее, чем anger; не растягивать слово сильно.

### `contempt` — презрение / холод
**Когда:** ровная громкость, но «сухой» тон.  
**Анимация:** минимальный scale `1.02–1.03`, почти статично, цвет включается чуть резче (`120–160 ms`).  
**Правило:** эмоция передаётся сдержанностью, а не амплитудой.

### `disgust` — отвращение
**Когда:** короткая негативная реакция, часто спад после пика.  
**Анимация:** scale `1.05` → мягкий откат `1.02`, лёгкий сдвиг вниз `+1 px`.  
**Правило:** один цикл «вздрогнул и отстранился», без повторов.

### `pain` — боль / надрыв
**Когда:** срыв голоса, нестабильность, иногда крик.  
**Анимация:** scale до `1.10–1.14` + нерегулярная тряска `≤ 0.7 px`.  
**Правило:** не делать «красивый» ритмичный shake; лучше чуть хаотичнее и короче.

### `shame` — стыд
**Когда:** тише обычного, уход интонации вниз.  
**Анимация:** scale `1.02`, сдвиг вниз `+1.5 px`, opacity `0.88 → 1`.  
**Правило:** движение внутрь/вниз, без яркого pop.

### `guilt` — вина
**Когда:** медленнее, с паузами, мягкие окончания.  
**Анимация:** как sadness, но ещё медленнее (`650–700 ms`) и без заметного scale выше `1.03`.  
**Правило:** не путать с страхом: тут нет тряски.

### `determination` — решимость
**Когда:** ровный сильный тон, уверенные ударения.  
**Анимация:** scale `1.05–1.07`, без bounce, без тряски, короткий hold на пике.  
**Правило:** слово должно ощущаться «твёрдым», не «прыгучим».

### `urgency` — срочность / давление
**Когда:** ускоренный темп, напор, незавершённые фразы.  
**Анимация:** scale `1.06–1.08` + лёгкий stretchX `1.02–1.04`.  
**Правило:** если рядом уже fear — приоритет у fear только на словах с дрожью.

### `command` — приказ
**Когда:** короткий императив, высокая энергия на ударном слове («Хватит!»).  
**Анимация:** быстрый набор scale до `1.12–1.14`, hold, без возвратного bounce, `shout = true`.  
**Правило:** особенно строго соблюдать один шрифт; цвет спикера — только при включённом тумблере.
Для кульминационной команды (`intensity ≥ 0.9`) допустим `tension = true`:
только активное слово плавно дрожит с амплитудой до `0.75 px`.
Использовать только на короткой фразе вроде «Вы что творите?! Хватит!».

### Восклицание — крупный пульс слова
Если слово содержит `!`, контейнер всего слова плавно пульсирует до
`scale 1.12–1.16`. Побуквенный фокус продолжает работать внутри него.
Если у слова уже есть `rage` или `tension`, пульс объединяется с тряской
этого слова; отдельная анимация строки не запускается.

Для кульминационных слов «Сдохни!» и «Хватит!» используется усиленный профиль:
пульс до `1.20–1.22` по высоте и мягкая горизонтальная тряска `±0.5–0.6 px`.

## 3.1 Удары и физическое действие: `jolt`

Единственный случай, когда разрешено двигать **всю строку целиком** —
удар, падение, грохот в кадре. Это озвучивает не голос, а само действие.

```
jolt = clamp(impactLoudness * kImpact, 0, 5.5)   // px
```

| Событие в кадре | `jolt` | Пример строки |
|---|---|---|
| Нажим, толчок | `1.5–2.5 px` | реплика с `rage` |
| Грохот мебели | `3–3.5 px` | `[грохот скамьи]` |
| Удар по телу | `4.5–5.5 px` | `[глухой удар]`, `[удар]` |

Правила:
- один цикл `~460 ms`, амплитуда затухает (`-1 → +0.55 → -0.2 → 0`), возврат точно в исходную точку;
- строка не должна уезжать за границы safe-area;
- не чаще одного `jolt` на строку и не чаще ~1 раза в секунду;
- при `prefers-reduced-motion` — `jolt = 0` полностью.

## 3.2 Плотность строк в сцене действия

Половина напряжения теряется, если в драке субтитры молчат. Поэтому:
- **все** реплики, включая обрывки и повторы, получают строку;
- паузы между репликами длиннее `1.2 s` заполняются описанием звука
  (`[глухой удар]`, `[хрип, борьба]`, `[свисток надзирателя]`);
- описания звука — белым цветом, без цвета спикера; правила motion см. ниже;
- в сцене драки допустимо до `~1 строка / 1.5 s` — так зритель чувствует ритм действия.

### Фоновые звуки в квадратных скобках

Описание звука — **один неделимый объект**, а не последовательность слов:

- вся строка появляется сразу;
- нет пословной окраски, увеличения и раздвижения соседних слов;
- по умолчанию строка полностью статична;
- motion разрешён только при `intensity ≥ 0.85` или явном флаге
  `soundMotion`, то есть для действительно сильного события.

Доступны только два профиля:

| `soundMotion` | Когда | Анимация всей строки |
|---|---|---|
| `impact` | сильный удар, падение, грохот | один scale-пик до `1.10` за `500 ms`; допустим `jolt` |
| `chaos` | паника, крики, интенсивная борьба | общая мелкая тряска `≤ 0.8 px` и scale `≤ 1.045` |

Примеры:
- `[гул столовой]`, `[лязг наручников]`, `[свисток надзирателя]` — статично;
- `[грохот скамьи]`, `[глухой удар]`, `[удар]` — `impact`;
- `[крики вокруг]`, `[хрип, борьба]` — `chaos`.

Даже при `soundMotion` отдельные слова внутри квадратных скобок никогда не
анимируются.

## 4. Как комбинировать эмоцию и голос

```
cap          = shout ? 1.20 : 1.10
finalScale   = clamp(baseScale * emotionScaleMul * accentMul, 1.02, cap)
finalStretch = clamp(baseStretch * emotionStretchMul, 1.00, 1.06)
finalPitchY  = 0 // нижняя граница активного слова всегда зафиксирована
finalTremor  = emotionTremor            // голос сам по себе тряску не включает
finalJolt    = hasImpactInFrame ? jolt : 0
```

Примеры:
- `fear` + тихий голос → маленькая тряска, почти без увеличения
- `anger` + громко → большой scale, быстрая атака, тряски нет
- `rage` + удар в кадре → scale `1.18`, акцент на втором слове, `jolt 3.5 px`
- `panic` + шум толпы → средний scale и непрерывная мелкая тряска
- `joy` + средний голос → лёгкий подъём и мягкий рост
- `whisper` + sadness → минимальный scale, уход вниз, без тряски

## 5. Синхронизация

1. Строка появляется целиком белым read-ahead (`opacity 0.9`).
2. Слой синхронизации бежит **по буквам**: timing слова равномерно
   делится на его буквы (`start…end` слова → `start` каждой буквы).
3. В момент начала звука буквы активируется плавный motion. Активная буква
   получает единственный акцентный цвет `#00A5FF`.
4. Все уже произнесённые буквы, включая завершённые слова, остаются
   окрашенными в `#00A5FF`.
5. **Волна по умолчанию — цвет, не размер.** Обычная речь не увеличивает
   буквы и не «дышит» строкой. Побуквенный `scale` включается только при
   громком акценте (`accent ≥ 1.08`), `shout` / `super`, или `cue.scale ≥ 1.08`.
6. Одновременно **всё текущее слово** может получить профиль эмоции
   (тряска, tension). **Целословный scale** — только супер-пик
   (`super`, `rage` / `rage-smooth`, impact-слова вроде «Сдохни» / «Хватит»).
7. После буквы её локальный motion возвращается к покою (`scale=1`). Нижняя
   граница буквы всегда зафиксирована (`transform-origin: center bottom`).

Исключение: описание фонового звука в квадратных скобках показывается сразу
целиком и не участвует в побуквенной синхронизации.

> Лаборатория `/motion-lab` может варьировать `font-weight` (400/500/700)
> для демонстрации эмоций. В плеере и мобильной ленте вес всегда Bold.

### Динамическое раздвижение строки

В спокойном состоянии сохраняется обычное расстояние между буквами. Когда текущая
буква увеличивается, она плавно раздвигает строку от себя в обе стороны:

```
scaleX = activeWordScale * stretchX
push = ceil(activeWordWidth * (scaleX - 1) / 2 + tremorPx)

wordsBeforeActive → translateX(-push)
activeWord       → scale(scaleX), translateX(0)
wordsAfterActive → translateX(+push)
```

- `margin`, ширина слов и межсловный пробел не меняются;
- соседние буквы сдвигаются с теми же duration и easing, с которыми растёт активная;
- при переходе к следующей букве предыдущее место плавно собирается, новое —
  раздвигается;
- `push` учитывает максимальное горизонтальное отклонение тряски, поэтому буквы
  не пересекаются даже на пике;
- перенос строки не должен меняться во время реплики;
- локальный фокус всегда движется по буквам, а эмоциональный профиль
  одновременно применяется к контейнеру текущего слова.

## 6. Жёсткие запреты

- Не менять `font-size`, `font-weight`, `letter-spacing` активного слова.
- Не использовать `translateY` для активного слова: `transform-origin` всегда
  `center bottom`, поэтому слово растёт только вверх от неизменной нижней границы.
- Исключение: экспериментальный мобильный режим `letterMotionMode = "lift"`
  поднимает только текущую букву: обычная речь на `0.55–0.8 px`, эмоциональные
  или растянутые слова на `0.9–1.25 px`. Высота и длительность зависят от
  тайминга слова, `stretch` и голосового акцента. В растянутых словах гласные
  получают более длинную фазу подъёма. Целословный scale в этом режиме разрешён
  только для слова с `!` внутри реплики `shout`.
- Не анимировать layout (`width`, `padding`, `margin`).
- Не допускать пересечения соседних слов даже на пике анимации.
- Не делать pop > `1.10` в обычной сцене и > `1.20` даже в крике.
- Не трясти всю строку реплики. `tension`, `rage` и `tremor` применяются только
  к текущему слову. Двигать строку целиком можно лишь для фонового звука
  в квадратных скобках (`jolt` на удар в кадре).
- Не ставить `shout` на всю сцену подряд: если кричит каждая строка, крик перестаёт читаться.
- Не назначать две эмоции на одно слово: выбираем одну доминирующую.
- Не включать motion-эффекты при `prefers-reduced-motion`, кроме цвета и scale ≤ `1.03`.

## 7. Данные на слово (контракт)

```json
{
  "text": "Сдохни!",
  "start": 38.35,
  "end": 39.16,
  "speakerId": "woman",
  "loudness": -4.1,
  "pitchHz": 320,
  "emotion": "rage",
  "intensity": 0.95,
  "shout": true,
  "scale": 1.18,
  "accent": 1.18,
  "stretch": 1.06,
  "pitchY": 2,
  "tremor": 0.5,
  "tremorPx": 0.8,
  "jolt": 3.5
}
```

Поля motion (`scale`, `accent`, `stretch`, `pitchY`, `tremor`, `tremorPx`, `jolt`) можно считать на пайплайне заранее и отдавать в плеер готовыми.  
`emotion` храним всегда — это источник правды для QA и ручной правки редактором.
